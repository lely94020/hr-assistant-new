M2 - 简历管理模块
一、模块概述
项目	说明
模块编号	M2
模块名称	简历管理
优先级	P0（核心模块）
核心技术	文档解析、LangChain、Milvus向量化
关联模块	M1岗位管理、M3智能筛选、M7面试评价
1.1 模块定位
简历管理是系统的核心模块，负责简历的上传、解析、存储和管理，是AI智能功能的数据基础。
1.2 技术亮点
●文档解析：支持PDF和Word格式简历内容提取
●AI结构化：使用LangChain + Qwen从文本中提取结构化信息
●向量存储：简历内容向量化后存入Milvus，支持语义检索

四、数据模型
4.1 简历表（resume）
字段名	类型	必填	说明
id	BIGINT	是	主键ID
candidate_name	VARCHAR(50)	是	候选人姓名
phone	VARCHAR(20)	否	手机号
email	VARCHAR(100)	否	邮箱
education	VARCHAR(20)	否	学历
school	VARCHAR(100)	否	毕业院校
major	VARCHAR(100)	否	专业
work_years	INT	否	工作年限
current_company	VARCHAR(100)	否	当前公司
current_position	VARCHAR(100)	否	当前职位
skills	JSON	否	技能标签数组
work_experience	JSON	否	工作经历
project_experience	JSON	否	项目经验
education_experience	JSON	否	教育经历
resume_summary	TEXT	否	AI生成的简历摘要
original_content	TEXT	否	简历原始文本内容
file_path	VARCHAR(500)	是	原始文件存储路径
file_name	VARCHAR(200)	是	原始文件名
file_type	VARCHAR(10)	是	文件类型：pdf/docx/doc
file_size	BIGINT	否	文件大小(字节)
milvus_id	VARCHAR(100)	否	Milvus向量ID
position_id	BIGINT	否	关联岗位ID
status	TINYINT	是	状态
parse_status	TINYINT	是	解析状态：0-未解析 1-解析中 2-成功 3-失败
is_deleted	TINYINT	是	软删除标记
created_at	DATETIME	是	创建时间
updated_at	DATETIME	是	更新时间

五、接口设计
5.1 接口清单
接口名称	方法	路径	说明
上传简历	POST	/api/v1/resumes/upload	上传单个/多个简历
获取简历列表	GET	/api/v1/resumes	分页查询简历
获取简历详情	GET	/api/v1/resumes/{id}	获取简历详情
下载简历	GET	/api/v1/resumes/{id}/download	下载原始文件
批量下载	POST	/api/v1/resumes/batch-download	批量下载简历
删除简历	DELETE	/api/v1/resumes/{id}	删除简历
关联岗位	PUT	/api/v1/resumes/{id}/bindPosition	关联到岗位
更新状态	PATCH	/api/v1/resumes/{id}/status	更新简历状态
重新解析	POST	/api/v1/resumes/{id}/reparse	重新解析简历
