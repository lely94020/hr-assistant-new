M3 - 智能简历筛选模块
一、模块概述
项目	说明
模块编号	M3
模块名称	智能简历筛选
优先级	P0（核心AI模块）
核心技术	Milvus向量检索、LangChain、RAG
关联模块	M1岗位管理、M2简历管理
1.1 模块定位
智能简历筛选是本项目的核心AI功能模块，利用向量检索技术实现基于语义的简历与岗位智能匹配。
1.2 技术亮点
● 向量语义检索：使用Milvus进行高性能向量相似度搜索
● RAG增强：检索结果结合LLM生成匹配分析报告
● 多维度匹配：不仅看关键词，更看语义相关性

三、功能详细说明
3.1 M3-F1 岗位匹配筛选
功能描述： 选择目标岗位，系统自动从简历库中检索最匹配的候选人。
筛选流程：

输入参数：
参数	类型	必填	说明
position_id	Long	是	目标岗位ID
top_n	Integer	否	返回数量，默认10，范围5-50
min_education	String	否	最低学历要求
min_work_years	Integer	否	最少工作年限
required_skills	Array	否	必须具备的技能
输出内容：
字段	说明
resume_id	简历ID
candidate_name	候选人姓名
match_score	匹配度分数（0-100）
similarity	向量相似度（0-1）
recommendation	推荐等级
match_analysis	匹配分析详情

3.2 M3-F2 自定义条件筛选
功能描述： HR输入自定义的筛选要求，进行智能检索。
使用场景：
● 岗位JD信息不完整时
● 需要特定条件的候选人
● 临时性筛选需求
输入示例：
"我需要一位有5年以上微服务开发经验的Java工程师，
最好有电商或金融行业背景，熟悉高并发系统设计"
处理流程：
1. 将自定义描述向量化
2. 在Milvus中检索相似简历
3. 生成匹配分析

3.3 M3-F3 匹配度评分
评分算法：
最终匹配分数 = 向量相似度分数 * 0.6 + 条件匹配分数 * 0.4

向量相似度分数 = cosine_similarity * 100

条件匹配分数 = (学历匹配 + 年限匹配 + 技能匹配) / 3
匹配等级划分：
分数范围	推荐等级	显示颜色
85-100	强烈推荐	绿色
70-84	推荐	蓝色
55-69	一般	灰色
0-54	不推荐	-

3.4 M3-F4 匹配分析报告
功能描述： 使用LangChain生成每份简历的详细匹配分析。
分析内容：
分析项	说明
匹配优势	候选人符合岗位要求的优势点（3-5条）
匹配短板	候选人可能的不足或需要考察的点（2-3条）
综合评语	100字左右的综合评价
面试建议	建议重点考察的方向
AI分析Prompt：
请分析以下候选人与目标岗位的匹配程度：

【目标岗位】
岗位名称：{position_name}
岗位职责：{job_description}
任职要求：{requirements}

【候选人信息】
姓名：{candidate_name}
学历：{education} - {school}
工作年限：{work_years}年
当前职位：{current_position} @ {current_company}
技能：{skills}
简历摘要：{resume_summary}

请按以下格式返回分析结果：
{
    "match_advantages": ["优势1", "优势2", "优势3"],
    "match_weaknesses": ["短板1", "短板2"],
    "overall_comment": "综合评语（100字）",
    "interview_suggestions": ["建议考察方向1", "建议考察方向2"]
}

3.5 M3-F5 批量标记
功能描述： HR可以批量标记简历的筛选结果。
标记选项：
● 通过初筛
● 不通过
● 待定
业务规则：
● 标记"通过初筛"后，简历状态变更为"初筛通过"
● 标记"不通过"后，简历状态变更为"已淘汰"

四、向量检索技术详解
4.1 Milvus检索流程
from pymilvus import Collection, connections

# 1. 连接Milvus
connections.connect("default", host="localhost", port="19530")

# 2. 获取Collection
collection = Collection("resume_vectors")
collection.load()

# 3. 准备查询向量（JD向量化）
jd_text = f"{job_description}\n{requirements}"
query_vector = embedding_model.embed(jd_text)

# 4. 执行向量检索
search_params = {
    "metric_type": "COSINE",  # 余弦相似度
    "params": {"nprobe": 10}
}

results = collection.search(
    data=[query_vector],
    anns_field="embedding",
    param=search_params,
    limit=top_n,
    output_fields=["resume_id"]
)

# 5. 获取检索结果
matched_resumes = []
for hits in results:
    for hit in hits:
        matched_resumes.append({
            "resume_id": hit.entity.get("resume_id"),
            "similarity": hit.score
        })
4.2 相似度计算
使用余弦相似度（Cosine Similarity）作为匹配度量：
similarity = cos(A, B) = (A · B) / (||A|| × ||B||)

其中：
- A：岗位JD向量
- B：简历向量
- 值域：[-1, 1]，越接近1越相似
