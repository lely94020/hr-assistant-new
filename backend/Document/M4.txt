M4 - 面试题生成模块
一、模块概述
项目	说明
模块编号	M4
模块名称	智能面试题生成
优先级	P0（核心AI模块）
核心技术	LangChain、Prompt Engineering
关联模块	M1岗位管理、M2简历管理
1.1 模块定位
利用LangChain和大模型能力，根据岗位JD和候选人简历智能生成个性化面试题目。
1.2 技术亮点
● 上下文感知：根据岗位要求和候选人背景生成针对性题目
● 多类型支持：技术题、行为题、情景题、开放题
● 参考答案：自动生成答案和评分要点
1.3 核心流程

三、功能详细说明
3.1 生成模式
3.1.1 基于岗位生成（M4-F1）
适用场景： 为某岗位准备通用面试题库
输入： 岗位JD（职责+要求）
输出： 与岗位相关的通用面试题
3.1.2 基于简历生成（M4-F2）
适用场景： 针对特定候选人准备面试
输入： 候选人简历信息
输出： 针对候选人经历的针对性问题
3.1.3 混合生成（M4-F3）
适用场景： 标准做法，综合考虑岗位和候选人
输入： 岗位JD + 候选人简历
输出： 既考察岗位技能，又针对候选人背景的综合题目

3.2 题目类型
类型	英文	说明	示例
技术类	Technical	考察专业技能和知识	"请介绍一下你对微服务架构的理解"
行为类	Behavioral	考察过往经历和行为模式	"请举例说明你如何处理团队冲突"
情景类	Situational	考察问题解决和应变能力	"如果项目deadline紧急，你会如何安排优先级"
开放类	Open-ended	考察思维深度和视野	"你认为未来5年这个行业会有什么变化"
3.3 难度等级
等级	说明	适用对象
初级	基础概念和常见场景	应届生、1-3年经验
中级	深入原理和复杂场景	3-5年经验
高级	架构设计和技术决策	5年以上、技术专家

3.4 AI生成Prompt
3.4.1 混合生成Prompt
你是一位资深的技术面试官，请根据以下信息生成面试题目。

【目标岗位】
岗位名称：{position_name}
岗位职责：
{job_description}

任职要求：
{requirements}

【候选人信息】
姓名：{candidate_name}
学历：{education} - {school} - {major}
工作年限：{work_years}年
当前职位：{current_position} @ {current_company}
技能标签：{skills}
工作经历摘要：{work_experience_summary}
项目经验摘要：{project_experience_summary}

【生成要求】
- 题目类型：{question_types}（可多选：技术类/行为类/情景类/开放类）
- 难度等级：{difficulty}（初级/中级/高级）
- 题目数量：{count}题
- 是否生成参考答案：{with_answer}

请按以下JSON格式返回：
{
    "questions": [
        {
            "type": "技术类",
            "difficulty": "中级",
            "question": "题目内容",
            "reference_answer": "参考答案（如需要）",
            "scoring_points": ["评分要点1", "评分要点2"],
            "source": "基于岗位要求/基于候选人经历"
        }
    ]
}

要求：
1. 技术类题目要结合岗位技术栈和候选人技能
2. 行为类题目要基于候选人的工作经历设计
3. 题目要有区分度，能考察真实能力
4. 参考答案要给出关键点，不要过于冗长

四、数据模型
4.1 面试题表（interview_question）
字段名	类型	必填	说明
id	BIGINT	是	主键ID
position_id	BIGINT	否	关联岗位ID
resume_id	BIGINT	否	关联简历ID
question_type	VARCHAR(20)	是	题目类型：technical/behavioral/situational/open
difficulty	VARCHAR(10)	是	难度：junior/middle/senior
question_content	TEXT	是	题目内容
reference_answer	TEXT	否	参考答案
scoring_points	JSON	否	评分要点数组
source	VARCHAR(50)	否	题目来源说明
is_saved	TINYINT	否	是否保存到题库
created_at	DATETIME	是	创建时间
4.2 SQL建表语句
CREATE TABLE interview_question (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    position_id BIGINT DEFAULT NULL COMMENT '关联岗位ID',
    resume_id BIGINT DEFAULT NULL COMMENT '关联简历ID',
    question_type VARCHAR(20) NOT NULL COMMENT '题目类型',
    difficulty VARCHAR(10) NOT NULL COMMENT '难度等级',
    question_content TEXT NOT NULL COMMENT '题目内容',
    reference_answer TEXT DEFAULT NULL COMMENT '参考答案',
    scoring_points JSON DEFAULT NULL COMMENT '评分要点',
    source VARCHAR(50) DEFAULT NULL COMMENT '题目来源',
    is_saved TINYINT DEFAULT 0 COMMENT '是否保存到题库',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_position (position_id),
    INDEX idx_resume (resume_id),
    INDEX idx_type (question_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='面试题表';
