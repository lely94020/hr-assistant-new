M5 - 录音管理模块
一、模块概述
项目	说明
模块编号	M5
模块名称	面试录音管理
优先级	P0
核心技术	语音识别（Qwen3-ASR-Flash）
关联模块	M2简历管理、M6面试摘要、M7面试评价
1.1 模块定位
管理面试录音文件，核心功能是将语音转换为文字，为后续摘要提取和智能评价提供数据基础。
1.2 技术亮点
● 语音识别：使用Qwen3-ASR-Flash阿里云语音大模型
● 长音频处理：支持1小时以上的面试录音
● 文字校对：支持人工修正识别错误

3.2 M5-F2 语音转文字
转写流程：

转写状态：
状态值	状态名称	说明
0	未转写	刚上传，未开始转写
1	转写中	正在进行语音识别
2	已完成	转写成功
3	转写失败	转写过程出错

3.3 语音识别技术方案
本项目采用 Qwen3-ASR-Flash 阿里云语音识别大模型。
模型特性：
特性	说明
模型名称	Qwen3-ASR-Flash
调用方式	阿里云 DashScope API
支持格式	mp3/wav/m4a/flac等主流音频格式
支持语言	中文、英文及中英混合
响应速度	流式输出，实时返回识别结果
集成示例：
import dashscope
from dashscope.audio.asr import Transcription

# 配置API Key
dashscope.api_key = "your_dashscope_api_key"

def transcribe_audio(file_path: str) -> str:
    """转写音频文件"""
    task = Transcription.async_call(
        model='qwen3-asr-flash',
        file_urls=[file_path],
        language_hints=['zh', 'en']
    )
    # 等待转写完成
    result = Transcription.wait(task.output.task_id)
    return result.output.results[0].transcription_text

# 使用示例
transcript = transcribe_audio("interview.mp3")

四、数据模型
4.1 面试录音表（interview_recording）
字段名	类型	必填	说明
id	BIGINT	是	主键ID
resume_id	BIGINT	是	关联简历/候选人ID
position_id	BIGINT	否	关联岗位ID
file_name	VARCHAR(200)	是	原始文件名
file_path	VARCHAR(500)	是	文件存储路径
file_type	VARCHAR(10)	是	文件类型
file_size	BIGINT	是	文件大小(字节)
duration	INT	否	录音时长(秒)
transcript	LONGTEXT	否	转换后的文字稿
transcript_status	TINYINT	是	转写状态
transcript_error	VARCHAR(500)	否	转写失败原因
interviewer	VARCHAR(50)	否	面试官
interview_date	DATE	否	面试日期
created_at	DATETIME	是	创建时间

4.2 SQL建表语句
CREATE TABLE interview_recording (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    resume_id BIGINT NOT NULL COMMENT '关联简历ID',
    position_id BIGINT DEFAULT NULL COMMENT '关联岗位ID',
    file_name VARCHAR(200) NOT NULL COMMENT '文件名',
    file_path VARCHAR(500) NOT NULL COMMENT '存储路径',
    file_type VARCHAR(10) NOT NULL COMMENT '文件类型',
    file_size BIGINT NOT NULL COMMENT '文件大小',
    duration INT DEFAULT NULL COMMENT '时长(秒)',
    transcript LONGTEXT DEFAULT NULL COMMENT '文字稿',
    transcript_status TINYINT NOT NULL DEFAULT 0 COMMENT '转写状态',
    transcript_error VARCHAR(500) DEFAULT NULL COMMENT '转写错误',
    interviewer VARCHAR(50) DEFAULT NULL COMMENT '面试官',
    interview_date DATE DEFAULT NULL COMMENT '面试日期',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_resume (resume_id),
    INDEX idx_status (transcript_status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='面试录音表';
