M6 - 面试摘要提取模块
一、模块概述
项目	说明
模块编号	M6
模块名称	面试摘要提取
优先级	P0
核心技术	LangChain、长文本处理
关联模块	M5录音管理、M7面试评价
1.1 模块定位
从面试文字稿中智能提取关键信息和结构化摘要，帮助HR快速了解面试内容，为后续评价提供基础。
1.2 技术亮点
● 长文本处理：处理几千到上万字的面试文字稿
● 结构化提取：提取关键问答、能力标签、亮点疑虑等
● 信息压缩：将长内容压缩为易读的摘要

三、功能详细说明
3.1 摘要提取内容
提取项	说明	字数建议
面试概要	面试整体情况概述	100-200字
核心问答	最重要的3-5个问答对	每个100-200字
技术能力体现	候选人展示的技术能力标签	3-8个标签
软技能体现	沟通、表达、逻辑等软技能	3-6个标签
亮点	面试中的突出表现	2-4条
疑虑点	需要进一步考察的地方	2-3条
候选人提问	候选人向面试官的提问	原文提取

3.2 摘要生成流程


3.3 AI提取Prompt
你是一位专业的HR助手，请从以下面试记录中提取结构化摘要。

【面试信息】
候选人：{candidate_name}
应聘岗位：{position_name}
面试时长：{duration}分钟

【面试文字稿】
{transcript}

请按以下JSON格式返回摘要：
{
    "summary_overview": "面试整体概述（150-200字，包含面试氛围、候选人整体表现等）",

    "key_qa": [
        {
            "question": "面试官提出的重要问题",
            "answer_summary": "候选人回答的要点概述（100字以内）",
            "answer_quality": "优秀/良好/一般/较差"
        }
    ],

    "technical_skills": ["技术能力标签1", "技术能力标签2"],

    "soft_skills": ["软技能标签1", "软技能标签2"],

    "highlights": [
        "亮点1：具体描述",
        "亮点2：具体描述"
    ],

    "concerns": [
        "疑虑1：具体描述",
        "疑虑2：具体描述"
    ],

    "candidate_questions": [
        "候选人提出的问题1",
        "候选人提出的问题2"
    ]
}

提取要求：
1. 核心问答选择最能体现候选人能力的3-5个问题
2. 技术能力标签要具体，如"微服务架构"而非"技术能力强"
3. 亮点和疑虑要有具体事例支撑
4. 回答质量判断要基于回答的完整性、逻辑性、专业性

3.4 长文本处理策略
问题： 面试文字稿可能有5000-10000字，超出模型单次处理能力。
解决方案：分块处理 + 汇总
from langchain.text_splitter import RecursiveCharacterTextSplitter

# 1. 文本分块
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=3000,
    chunk_overlap=200
)
chunks = text_splitter.split_text(transcript)

# 2. 每块提取关键信息
chunk_summaries = []
for chunk in chunks:
    summary = extract_chunk_summary(chunk)
    chunk_summaries.append(summary)

# 3. 汇总所有块的信息
final_summary = consolidate_summaries(chunk_summaries)

四、数据模型
4.1 面试摘要表（interview_summary）
字段名	类型	必填	说明
id	BIGINT	是	主键ID
recording_id	BIGINT	是	关联录音ID
resume_id	BIGINT	是	关联简历ID
summary_overview	TEXT	是	面试概要
key_qa	JSON	否	核心问答
technical_skills	JSON	否	技术能力标签
soft_skills	JSON	否	软技能标签
highlights	TEXT	否	亮点
concerns	TEXT	否	疑虑点
candidate_questions	TEXT	否	候选人提问
created_at	DATETIME	是	创建时间
updated_at	DATETIME	是	更新时间
4.2 SQL建表语句
CREATE TABLE interview_summary (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    recording_id BIGINT NOT NULL COMMENT '关联录音ID',
    resume_id BIGINT NOT NULL COMMENT '关联简历ID',
    summary_overview TEXT NOT NULL COMMENT '面试概要',
    key_qa JSON DEFAULT NULL COMMENT '核心问答',
    technical_skills JSON DEFAULT NULL COMMENT '技术能力标签',
    soft_skills JSON DEFAULT NULL COMMENT '软技能标签',
    highlights TEXT DEFAULT NULL COMMENT '亮点',
    concerns TEXT DEFAULT NULL COMMENT '疑虑点',
    candidate_questions TEXT DEFAULT NULL COMMENT '候选人提问',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_recording (recording_id),
    INDEX idx_resume (resume_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='面试摘要表';
