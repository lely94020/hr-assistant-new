M8 - 候选人对比模块
一、模块概述
项目	说明
模块编号	M8
模块名称	候选人对比
优先级	P1
核心技术	LangChain、数据可视化
关联模块	M2简历管理、M7面试评价
1.1 模块定位
支持多个候选人的横向对比分析，利用AI生成对比报告，辅助HR做出最终的录用决策。
1.2 技术亮点
● 多维度对比：基础信息、评分、能力全方位对比
● 可视化展示：雷达图、柱状图直观呈现差异
● AI决策建议：智能分析并给出推荐排名

二、功能清单
功能编号	功能名称	功能描述	优先级
M8-F1	选择对比候选人	选择2-5个候选人进行对比	P0
M8-F2	基础信息对比	对比学历、经验、技能等	P0
M8-F3	评分对比	对比各维度评分	P0
M8-F4	雷达图展示	用雷达图可视化对比	P1
M8-F5	AI对比分析	AI生成对比分析报告	P0
M8-F6	推荐排名	AI给出候选人推荐排名	P0
M8-F7	导出对比报告	导出对比结果为PDF	P2

三、功能详细说明
3.1 对比维度
类别	对比项	数据来源
基础信息	学历、院校、专业	简历
工作背景	工作年限、当前公司、当前职位	简历
技能匹配	岗位要求技能的匹配程度	简历+筛选
面试评分	六大维度评分及综合分	评价

四、数据模型
4.1 候选人对比表（candidate_comparison）
字段名	类型	必填	说明
id	BIGINT	是	主键ID
position_id	BIGINT	是	关联岗位ID
resume_ids	JSON	是	参与对比的简历ID列表
comparison_data	JSON	否	对比数据快照
ai_analysis	JSON	否	AI分析结果
ranking	JSON	否	推荐排名
created_by	BIGINT	否	创建人
created_at	DATETIME	是	创建时间
4.2 SQL建表语句
CREATE TABLE candidate_comparison (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    position_id BIGINT NOT NULL COMMENT '岗位ID',
    resume_ids JSON NOT NULL COMMENT '简历ID列表',
    comparison_data JSON DEFAULT NULL COMMENT '对比数据',
    ai_analysis JSON DEFAULT NULL COMMENT 'AI分析',
    ranking JSON DEFAULT NULL COMMENT '排名',
    created_by BIGINT DEFAULT NULL COMMENT '创建人',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_position (position_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='候选人对比表';

五、接口设计
5.1 接口清单
接口名称	方法	路径	说明
创建对比	POST	/api/v1/comparison/create	创建候选人对比
获取对比结果	GET	/api/v1/comparison/{id}	获取对比详情
AI对比分析	POST	/api/v1/comparison/{id}/analyze	生成AI对比分析
导出报告	GET	/api/v1/comparison/{id}/export	导出PDF报告
对比历史	GET	/api/v1/comparison/history	获取对比历史列表
